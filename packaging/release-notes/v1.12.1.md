jekyll-vitepress-theme 1.12.1 keeps `/next/` and older docs versions out of search results, so search engines rank your stable docs instead of splitting each page across its copies.

```sh
bundle update jekyll-vitepress-theme
```

## Fixed

* **Only the stable docs are indexed.** Pages in `/next/` and in older versions kept online repeat most of the stable pages, and 1.12.0 let search engines index all of them: on one site that made 234 duplicate pages indexable. Those versions now say `noindex,follow`, their sitemaps and `llms.txt` stay empty, and `robots.txt` lists only the stable sitemap. Readers still reach every version through the version selector. Set `seo.index_versions: true` under `jekyll_vitepress` to have them indexed as before. By @crmne
