jekyll-vitepress-theme 1.10.1 makes "Last updated" mean what it says: each page now shows when it was last committed, not when your CI checked it out. It also brings every dependency up to date.

```sh
bundle update jekyll-vitepress-theme
```

## Fixed

* **"Last updated" comes from Git.** The footer date is now the last commit that touched each page, read in one `git log` pass per build, so a fresh CI checkout no longer stamps every page with the build time. Files that are untracked or have uncommitted changes keep their modification time, so a preview shows the page you're editing as just updated, and `jekyll_vitepress.last_updated_at` in front matter still wins. In CI, check out the full history with `fetch-depth: 0`; with a shallow clone, pages older than the fetched history fall back to the checkout time and the build prints a warning. Reported in #21 by @miharp, fixed by @crmne.

## Changed

* **Rouge 5 is allowed, and Rouge 4.1 is the minimum.** The theme works with Rouge 5 as soon as Jekyll allows it. The old minimum of 3.0 never worked: the default dark code theme, `github.dark`, first ships in Rouge 4.1. By @crmne
* **Dependencies are current, and updates arrive weekly.** The development tooling is on its current major versions, the locked gems are updated, and Dependabot now opens grouped weekly updates for npm, gems, and GitHub Actions. By @crmne
