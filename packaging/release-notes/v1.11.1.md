jekyll-vitepress-theme 1.11.1 fixes links in the home page body: they now open their page normally, and the menu keeps working afterwards.

```sh
bundle update jekyll-vitepress-theme
```

## Fixed

* **Links on the home page open their page, and the menu keeps working.** A link in the Markdown body of the home page (below the hero and features) was sent to the docs content frame, which only exists on pages with a sidebar. Turbo then swapped the whole page in a way the theme's scripts didn't follow, so the page could fail to show and, on small screens, the menu and sidebar stopped opening. Links on the home page now load their page in full, and links between docs pages still swap only the content. By @crmne
