jekyll-vitepress-theme 1.10.0 makes the Markdown your site hands to people and to LLMs read as Markdown. Copy page, the `.md` file next to each page, and `llms-full.txt` used to carry a page's HTML exactly as it was written; they now carry clean Markdown.

```sh
bundle update jekyll-vitepress-theme
```

## New

* **Page exports convert HTML to Markdown.** Headings, links, lists, emphasis, tables, and highlighted code become their Markdown forms, and scripts, media, buttons, and decorative elements are dropped. Fenced code and code spans stay exactly as written, and a page without HTML exports unchanged. On the RubyLLM docs, `llms-full.txt` went from 36,237 lines, about 8,900 of them markup, to 15,949 lines with none. By @crmne
* **Home pages keep their hero.** The headline, tagline, and action links from `hero` front matter now open the page's export, so an LLM reads what your home page says first:

  ```markdown
  # RubyLLM

  The Ruby AI framework

  Build AI features *the Ruby way*: models, tools, agents, sandboxed code, evaluations, and Rails conventions, designed together, with one consistent API.

  [Get started](/next/getting-started/)
  ```

  By @crmne
* **Code block titles survive.** A fenced code block's `data-title` becomes a bold line above it in the export, linked when the block also has a `data-href`. By @crmne

## Fixed

* **Kramdown attribute lines no longer leak into exports.** Lines such as `{: .note }` are removed from Copy page, `.md` files, and `llms-full.txt`. By @crmne
