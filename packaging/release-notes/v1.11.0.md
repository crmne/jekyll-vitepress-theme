jekyll-vitepress-theme 1.11.0 gives search engines the same dates your readers see: every entry in the generated `sitemap.xml` now carries a `<lastmod>` from the page's last commit, so crawlers and IndexNow can tell which pages changed.

```sh
bundle update jekyll-vitepress-theme
```

## New

* **Sitemap entries are dated by Git.** Each URL in `sitemap.xml` gets `<lastmod>` from the last commit that touched its source file, the same date the "Last updated" footer shows. An explicit `date_modified`, `last_modified_at`, or `jekyll_vitepress.last_updated_at` in front matter still wins. Pages Git cannot date (untracked, uncommitted, or older than a shallow clone's history) get no `<lastmod>` rather than the build time, so a rebuild never claims that every page changed. In CI, check out the full history with `fetch-depth: 0`. Before this release, only pages with an explicit modification date had one. By @crmne
